# Assignment 1 Resume and Reflection Design

## Goal

Create a new two-page, submission-ready PDF based on the supplied Assignment 1 document without modifying the source file.

## Layout

- Page 1 is an English AI/ML resume. Place the supplied headshot in a rounded square at the upper right; keep the name, email, GitHub, and technical focus in a left-aligned header block.
- Page 2 is the UGBA 117 Prompt Engineering Reflection. It remains text-first and uses a compact five-element prompt table followed by three focused reflective paragraphs.
- Use navy section headings, readable margins, and ATS-friendly text. No unsupported achievements or metrics will be added.

## Content Treatment

- Preserve all supplied education, project, publication, honor, and skill facts.
- Tighten project bullets so each begins with technical ownership and separates platform capability from implementation detail.
- Strengthen the reflection around the initial prompt weakness, the revised prompt structure, factual verification, and a concrete lesson about human review.

## Acceptance Criteria

- A two-page PDF is written under `output/pdf/`.
- The first page contains the supplied headshot and the second page does not.
- The text contains the named Assignment 1 sections and the required resume facts.
- Rendered pages have no clipped, overlapping, or unreadable content.
